# Woodline · Заказы

Приложение для учёта заказов Woodline: заказы с Узум и клиенты с сайта, сроки доставки, оплаты и аналитика.

- Открывается во весь экран с иконки на телефоне (PWA).
- Вход по email и паролю (Firebase Authentication). Самостоятельная регистрация выключена: аккаунты добавляет владелец в консоли Firebase → Authentication → Users.
- Заказы хранятся в Cloud Firestore (проект `woodline-zakazy`, коллекция `orders`). В этом репозитории данных клиентов нет.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Всё приложение: разметка, стили и логика |
| `manifest.webmanifest` | Название, иконки и цвета для установки на телефон |
| `sw.js` | Кэш для быстрого открытия и работы без интернета |
| `logo.svg`, `*.jpg` | Логотип и фото с woodlinepro.uz |
| `icon-*.png`, `apple-touch-icon.png` | Иконки приложения |

Публикуется через GitHub Pages из ветки `main`.
